MACHINE LEARNING / URL SECURITY

Beyond 99.9%
Shortcut-Robust Phishing URL Detection

Four classifiers on LegitPhish (stratified 80/20) reach about 99.9% accuracy, but they learn dataset shortcuts (HTTPS, www, empty path, raw IP hosts). We expose these shortcuts, build an evasion benchmark of realistic attacker edits and normal page variations, and propose format-randomised training with suspicious-domain features.

08 / EXTERNAL VALIDATION · KEY RESULT

Trained on LegitPhish, tested on unseen PhiUSIIL URLs

Source: x2_cross_dataset_phiusiil.csv

Because both datasets share the shortcut, the standard model scores almost perfectly on PhiUSIIL too. Removing the shortcut completely (pure FRT, D3/D4) gives the best robustness but loses real-data accuracy. Mixed FRT (D6: clean URLs + two randomised copies) keeps both. "Format-matched" uses only the {{ x2meta['phishing_group_sizes']?.['Looks like legitimate format (HTTPS + www + homepage)'] }} real PhiUSIIL phishing URLs written exactly like legitimate ones (HTTPS + www + homepage), where no format cue can help.
